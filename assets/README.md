# Assets

The new Project V runtime does not depend on the old temporary Michael/Meshy character or its manually supplied textures. Those prototype assets have been retired.

This public repository should not contain extracted GTA V game data. User-owned Xbox 360 resources belong in local/private storage or the user's R2 source bucket and are accessed through the VFS/RPF pipeline.

The existing CC0 weapon stand-ins may remain for isolated renderer/gameplay tests, but they are not authoritative GTA V assets and are not part of the compatibility target.
