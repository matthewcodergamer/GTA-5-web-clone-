# Legacy gameplay prototype

Files in this directory are retained only as reference material from the pre-compatibility Three.js prototype (mobile controls, HUD/minimap, camera and gameplay experiments).

The new root site and Engine Lab do not load these files. New runtime work belongs under `packages/`, `apps/`, `tools/` and `native/`.

When real Xbox 360 world/player resources are decoded, useful gameplay ideas can be migrated into `packages/gameplay` without restoring direct dependencies on temporary Michael assets.
