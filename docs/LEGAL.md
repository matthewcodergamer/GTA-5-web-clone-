# Project data boundary

Project V is designed around bring-your-own-files. The public repository contains original compatibility/runtime code and tiny synthetic test data only.

Do not commit GTA V RPF archives, XEX/ISO/7z game distributions, ripped models/textures/audio/scripts, encryption keys/credentials, or generated exports that contain proprietary game content.

Local/R2 source data remains under the user's control. The compatibility runtime should reference it by path/range and generate rebuildable caches outside Git.
